# Atlas AI – Android (APK)

Bu depo, Lovable'daki Atlas AI uygulamasının (https://intuitive-web-tools.lovable.app) Android sürümüdür.
Uygulama Capacitor ile paketlenir ve canlı Lovable uygulamasını açar; Lovable'da yaptığınız her değişiklik
uygulamaya otomatik yansır, yeniden APK yapmaya gerek yoktur.

## APK'yı indirme
GitHub → **Releases** → en son sürüm → **Atlas-AI.apk**.

## Yeniden derleme
`master` dalına her gönderimde GitHub Actions APK'yı yeniden derler (Actions → "Atlas AI APK" → Run workflow ile elle de çalıştırılabilir).

- Simge: `resources/icon.png`
- Açılış ekranı: `resources/splash.png`
